# BMI Calculator 🚀

A lightweight, clean, and responsive web application designed to calculate Body Mass Index (BMI) instantly. Developed with HTML5, JavaScript, and custom-styled CSS featuring a vibrant gradient UI and a playful animated cursor.

---

## ✨ Features

* **Real-Time Computation:** Instantly calculates and evaluates BMI results upon input.


* **Health Categorization:** Automatically classifies results into **Under Weight**, **Normal**, or **Over Weight**.


* **Input Validation:** Built-in validation checks to ensure users provide proper and valid height (in cm) and weight (in kg) values.


* **Modern Aesthetic:** Styled with a sleek dual-tone gradient background, smooth button hover animations, and a custom animated cursor.



---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6)


* **Styling:** Custom CSS Flexbox, Gradients, and Transitions
